# 💸 모임 지출 정산 프로그램 (Streamlit Settlement App)

가족 모임, 여행, 동호회 등에서 발생하는 복잡한 지출 내역을 투명하고 깔끔하게 계산하고, **대표 수납자(총무) 중심의 최소 1방향 송금 경로**를 도출해 주는 웹 기반 정산 프로그램입니다.

---

## ✨ 주요 기능

### 1. 👥 동적 가족 구성원 관리
- 기본 5가족(가율, 소율, 서아, 시윤, 은율) 기본 세팅 제공.
- 각 가족의 우측 **❌ 버튼**을 이용해 손쉽게 삭제 및 실시간 인원수 조정 가능.
- 사이드바 하단에서 새 가족 이름과 인원수를 입력하여 **실시간 추가** 가능.

### 2. 💳 유연한 지출 등록 및 3가지 분담 방식
- **가족수 기준 균등 분담 (1/N)**: 참여한 가족 수대로 균등하게 1/N 분담.
- **참여 인원수 비례 분담**: 각 가족의 실제 인원수 가중치에 비례하여 공평 분담.
- **사용자 지정 비율 분담 (%)**: 가족별로 직접 % 비율을 입력하여 맞춤 분담.
- 지출 항목별 메모(상세 품목, 숙소 호실 등) 입력 기능 지원.

### 3. 👑 대표 수납자(총무) 중심의 1방향 최적 송금
- **수납자 직접 지정 또는 자동 선정**: 낼 돈이 있는 가족은 **모두 지정된 총무에게 1번만 송금**(`📥`).
- **초과 지출자 환급**: 본인 분담금보다 더 많이 지출한 가족에게는 **총무가 모은 돈에서 차액을 다시 송금**(`📤`).
- **총무 최종 남는 금액 상세 설명**: 총무가 받은 돈에서 돌려준 뒤 남는 잔액이 **총무 본인이 선결제하고 최종 회수하는 정산금(지출액 - 분담금)**임을 명확히 표시.

### 4. 📸 고화질 정산 결과 이미지 카드 생성 (Pretendard 폰트)
- 단톡방, 메신저 공유에 최적화된 **고해상도 PNG 요약 카드** 원클릭 생성 및 다운로드.
- 요즘 가장 인기 있는 모던 오픈소스 폰트인 **Pretendard(프리텐다드)** 적용으로 글자 깨짐 없는 세련된 디자인 제공.

### 5. 💬 카카오톡 원클릭 공유 텍스트 자동 생성
- 지출 요약, 분담 기준(1/N 참여자, 비율%), 송금 계좌 안내 및 총무 최종 정산 내역이 포함된 공지 텍스트를 버튼 하나로 복사.

### 6. 🔒 접속 비밀번호 보안 잠금 (Streamlit Cloud 최적화)
- 비공개 모임 정산 내역을 보호하기 위해 웹 접속 시 비밀번호 인증 카드 UI 제공.
- Streamlit의 `st.secrets` 및 `.streamlit/secrets.toml`을 활용한 안전한 패스워드 관리 지원.

### 7. 💾 데이터 백업 및 복원
- 등록된 지출 및 가족 내역 전체를 JSON 파일로 백업 다운로드하고, 언제든 다시 불러와 복원 가능.

## 🛠️ 기술 스택

- **UI / Web Framework**: Python 3.12+, [Streamlit](https://streamlit.io/)
- **데이터 처리**: Pandas
- **시각화 & 이미지 생성**: Pillow (PIL), Pretendard Font
- **로깅 시스템**: Rich (콘솔 및 `코드파일명_YYMMDD.log` 실시간 파일 듀얼 로깅)
- **보안/인증**: HMAC Timing-Attack Resistant Password Authentication

## 🚀 로컬 실행 방법

### 1. 패키지 설치
```bash
pip install -r requirements.txt
```

### 2. 로컬 실행
```bash
streamlit run main.py
```
> 기본 접속 비밀번호는 `1234`로 설정되어 있으며, `.streamlit/secrets.toml` 파일의 `APP_PASSWORD`에서 변경하실 수 있습니다.

## ☁️ Streamlit Community Cloud 배포 가이드

1. GitHub 저장소(`https://github.com/kzoro4747/WON`)를 생성하고 코드를 푸시합니다.
2. [share.streamlit.io](https://share.streamlit.io/)에 로그인 후 **New app**을 누릅니다.
3. 저장소(`kzoro4747/WON`), 브랜치(`master`), 메인 파일(`main.py`)을 선택하고 배포합니다.
4. 배포 후 대시보드의 **[Settings] -> [Secrets]** 에 접속하여 비밀번호를 설정합니다:
   ```toml
   APP_PASSWORD = "가족들과_공유할_비밀번호"
   ```

# 💸 모임 지출 정산 프로그램 (Streamlit Settlement App)

모임이나 여행에서 발생한 여러 가족의 지출 내역을 효율적으로 정산하고, 송금 횟수를 최소화할 수 있도록 돕는 웹 기반 정산 프로그램입니다.

---

## ✨ 주요 기능

1. **👥 동적 가족 그룹 관리**
   - 기본 가족 구성원(가율-4인, 소율-3인, 서아-4인, 시윤-4인, 은율-4인) 세팅 제공.
   - 각 가족의 우측 **❌ 버튼**을 이용해 동적으로 삭제 가능.
   - 사이드바 하단에서 새 가족 이름과 인원수를 적어 **실시간 추가** 가능.

2. **💳 유연한 지출 등록 및 분담**
   - 지출 항목별로 지불한 가족, 금액, 참여자 목록을 개별 설정 가능.
   - **가족수 기준 균등 분담(1/N)**과 **참여 인원수 비례 분담**의 두 가지 분담 방식 지원.

3. **📊 직관적인 시각화 및 대시보드**
   - 총 지출금액 및 가족별 실제 지불액 요약 테이블 제공.
   - 각 가족의 최종 잔액(돌려받기/보내기)을 나타내는 **바 차트(Bar Chart)** 시각화.

4. **💸 최적 송금 가이드 (송금 최소화)**
   - 그리디(Greedy) 현금 흐름 최소화 알고리즘을 사용해 불필요한 이중 송금을 없애고 **최소한의 송금 경로**를 도출.

5. **💬 카카오톡 공유용 공지 텍스트 복사**
   - 정산이 끝나면 클릭 한 번으로 메신저(카톡 등) 단톡방에 바로 올릴 수 있는 서식화된 정산 공지문 자동 생성.

6. **💾 데이터 백업 및 복구**
   - 현재 등록된 가족 및 지출 내역 전체를 JSON 파일로 백업하고, 추후 다시 업로드하여 복원 가능.

---

## 🛠️ 기술 스택

- **언어**: Python 3.12+
- **UI 프레임워크**: Streamlit (웹 브라우저 기반 GUI)
- **데이터 분석 및 시각화**: Pandas
- **로깅 시스템**: Rich (터미널 및 실시간 파일 듀얼 로깅)

---

## 📂 파일 구조

- `main.py`: Streamlit 웹 애플리케이션 진입점 및 UI 렌더링.
- `calculator.py`: 가족 정보 객체, 지출 객체, 송금 최소화 정산 알고리즘 코어 로직.
- `logger_utils.py`: 터미널 출력 및 `코드파일명_YYMMDD.log` 형식의 실시간 듀얼 로깅 유틸리티.
- `test_calculator.py`: 정산 알고리즘 무결성 검증용 Unittest 모듈.

---

## 🚀 구동 및 테스트 방법

### 1. 의존성 패키지 설치
가상환경이 활성화된 상태에서 아래 라이브러리를 설치합니다.
```powershell
pip install streamlit pandas rich
```

### 2. 정산 웹 앱 실행
```powershell
streamlit run main.py
```
실행 후 기본 브라우저에 `http://localhost:8501`이 자동으로 실행됩니다.

### 3. 단위 테스트 실행
정산 알고리즘의 유효성을 검증하기 위한 단위 테스트를 구동합니다.
```powershell
python -m unittest test_calculator.py
```

---

## 📝 로깅 규칙

프로그램이 구동되거나 테스트가 실행되면 다음과 같은 실시간 로그 파일이 자동 생성됩니다.
- `main_YYMMDD.log`: 웹 앱 사용 중 발생한 지출 추가/삭제, 가족 변동 및 세션 로그.
- `calculator_YYMMDD.log`: 핵심 정산 및 송금 알고리즘 매칭 연산 로그.
- `test_calculator_260528.log`: 단위 테스트 검증 단계 로그.
